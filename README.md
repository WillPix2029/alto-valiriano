# Zaldrīzes – Aprenda Alto Valiriano

App estilo Duolingo (React + Vite) para falantes de português aprenderem Alto Valiriano.

```
npm install
npm run dev      # desenvolvimento
npm run build    # gera dist/
npx serve dist   # servir o build
```
